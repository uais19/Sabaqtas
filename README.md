# Sabaqtas

ИИ-платформа для обучения казахстанских школьников 7–12 классов.

Три ключевые особенности:

1. **Адаптивная диагностика.** Система идёт вниз по цепочке тем-пререквизитов и
   находит корневой пробел в знаниях — часто он на несколько классов ниже текущего.
2. **Режим наставника.** ИИ ведёт ученика к ответу наводящими вопросами и
   никогда не называет ответ сам.
3. **Ответы только по учебникам.** Все ответы ИИ строго основаны на загруженных
   школьных учебниках (RAG) и всегда содержат ссылку на параграф и страницу.

Язык интерфейса — русский. ИИ отвечает на русском или казахском.

## Стек

- **Frontend:** чистый HTML / CSS / JavaScript. Без фреймворков, без сборки.
- **Backend:** Python + FastAPI (пишет отдельный разработчик).
- **База данных:** Supabase Postgres.
- **ИИ:** Google Gemini API.

## Как запустить frontend

Отдельная сборка не нужна — это обычные статические файлы.

Самый простой способ: открыть `frontend/index.html` в браузере.

Либо поднять локальный сервер (ближе к реальным условиям, корректно работают
относительные пути и запросы к бэкенду):

```bash
python -m http.server 5500 --directory frontend
```

После этого открыть в браузере `http://localhost:5500`.

## Как собрать базу для RAG (chunks.json)

ИИ отвечает только по учебникам. Чтобы это работало, тексты учебников заранее
режутся на куски, и для каждого куска считается эмбеддинг — числовой вектор,
по которому потом ищут подходящий фрагмент.

Эмбеддинги считаются **заранее, на своём компьютере**, а не во время работы
сайта. Во время работы функция на сервере считает эмбеддинг только для вопроса
ученика, а векторы учебника уже лежат готовыми в `frontend/api/chunks.json`.

Исходный текст лежит в `content/math5-drobi.txt` — реальные фрагменты
учебника «Математика, 5 класс, часть 1» (Әбілқасымова А.Е.), §21–§23.
Каждый кусок начинается со строки
с метаданными:

```
### Математика | 5 класс | часть 1 | §12 | стр. 45
Текст абзаца...
```

Шестое поле `| placeholder` в конце строки помечает тестовый кусок. Пометка
попадает в метаданные, а не в текст для модели. Скрипт громко напомнит о таких
кусках в итоге сборки. В `math5-drobi.txt` заглушек нет — там настоящий текст
учебника.

### Что нужно

Python 3 и библиотека `requests`:

```bash
pip install requests
```

### Ключ Gemini

Ключ читается из переменной окружения `GEMINI_API_KEY`. В коде его нет и быть
не должно.

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY = "ваш-ключ"
```

Linux и macOS:

```bash
export GEMINI_API_KEY="ваш-ключ"
```

### Запуск

```bash
python tools/build_chunks.py
```

Скрипт покажет ход работы по кускам, а в конце — сколько кусков получилось и
сколько весит файл. Результат: `frontend/api/chunks.json`.

Этот файл **коммитится в репозиторий**: серверной функции он нужен во время
деплоя, а пересобирать его на каждом запуске незачем.
