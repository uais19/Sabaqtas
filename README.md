# Sabaqtas

**ИИ-напарник по учёбе, который находит корневой пробел в знаниях школьника и не решает задачи за него.**

Работающий прототип: **https://sabaqtas.vercel.app**

Проект для Future Minds Hackathon 2026, трек Social Impact.

---

## Идея

Ученик 8 класса не решает квадратные уравнения. Обычная платформа даст ему ещё двадцать таких же задач. Не поможет — потому что дыра не там: у него пробел в дробях за 5 класс, и всё, что стоит на дробях, ломается.

Sabaqtas спускается по цепочке тем вниз, пока ученик не начнёт отвечать верно, и строит план обучения от найденного пробела, а не от текущей темы класса.

### Три отличия

**1. Корневой пробел.** Диагностика идёт вниз по цепочке тем-пререквизитов: 8 класс → 7 → 6 → 5. Останавливается там, где ученик отвечает верно. Точка перелома и есть настоящая причина.

**2. Режим наставника.** Переключатель «Объясни» / «Помоги решить самому». Во втором режиме ИИ ведёт наводящими вопросами и не называет конечный ответ. Именно поэтому платформу можно разрешить в школе — в отличие от универсального чат-бота, который решает вместо ученика.

**3. Только из учебника, на двух языках.** Ответ строится по фрагментам настоящих казахстанских учебников и всегда сопровождается ссылкой на параграф. Чего в учебнике нет — ИИ честно не говорит. Отвечает на русском и на казахском; вопрос на одном языке может найти фрагмент на другом.

## Стек

- **Фронтенд:** чистый HTML, CSS и JavaScript. Без фреймворков, без сборки — сознательное решение: страница лёгкая, а каждую строку кода можно объяснить.
- **Серверная часть:** одна serverless-функция на Vercel (`frontend/api/ask.js`, Node.js). Существует ради двух вещей: спрятать ключ Gemini и выполнить поиск по учебнику.
- **ИИ:** Google Gemini — эмбеддинги `gemini-embedding-2` для поиска, текстовые модели для ответов.
- **Хранение:** JSON-файлы в репозитории и `localStorage` браузера. Отдельной базы данных нет — условия кейса это прямо допускают. Схема Postgres спроектирована и остаётся следующим шагом.

## Как это работает

```
Браузер (HTML/CSS/JS, профиль и прогресс в localStorage)
        │  POST /api/ask
        ▼
Serverless-функция на Vercel  (frontend/api/ask.js)
  ключ в переменной окружения
  поиск по chunks.json, порог отсечения
        ▼
      Gemini API
```

### Поиск по учебнику

**Заранее, на своём компьютере:** текст учебника режется на куски по метаданным, для каждого куска считается эмбеддинг — числовой вектор, по которому потом ищут по смыслу. Результат складывается в `frontend/api/chunks.json` и коммитится в репозиторий.

**Во время работы:** вопрос ученика превращается в вектор, сравнивается со всеми кусками, берутся пять ближайших.

### Порог отсечения — гарантия в коде

Если лучший кусок учебника похож на вопрос меньше чем на **0.6**, функция возвращает «Этого нет в загруженных учебниках» и **модель не вызывается вообще**. Это не просьба к модели вести себя хорошо, а `return` в функции до обращения к ИИ.

Побочный эффект: посторонние вопросы не тратят дневной лимит запросов.

Внутри диалога с наставником фрагменты ищутся по **первому вопросу диалога**, а не по текущей реплике: короткое «не знаю» само по себе не похоже ни на один параграф, и порог отсекал бы его раньше, чем наставник успел бы ответить. Тему задаёт первый вопрос, он же проходит порог.

### Экономия дневного лимита

Бесплатный тариф Gemini даёт около 20 генераций в сутки на каждую модель. Три уровня защиты:

1. **Кэш в браузере** — повторный вопрос отвечается без обращения к сети.
2. **Заготовленные ответы** (`frontend/api/answers.json`) — набор типовых вопросов, сгенерированных заранее и уехавших вместе с деплоем. Проверяются до эмбеддинга, отвечаются за 200–600 мс и не тратят лимит вовсе. Благодаря им демонстрация работает даже при полностью исчерпанной квоте.
3. **Пул резервных моделей** — при отказе одной модели запрос уходит следующей.

## Загруженные учебники

Учебники из официального перечня: **Әбілқасымова А.Е.** (математика, алгебра). Используются короткие фрагменты со ссылкой на параграф.

| Учебник | Параграфы | Тема |
|---|---|---|
| Математика, 5 класс, ч. 1 | §21, §22, §23 | Обыкновенные дроби: общий знаменатель, сравнение, сложение и вычитание |
| Математика, 6 класс, ч. 1 | §13 | Сложение рациональных чисел с разными знаками |
| Алгебра, 7 класс, ч. 2 | §31, §32 | Разность квадратов, квадрат суммы и разности |
| Алгебра, 8 класс, ч. 1 | §6, §7 | Квадратные уравнения, дискриминант, формула корней |

Всего 30 фрагментов. Корпус покрывает всю цепочку диагностики — можно спросить про любую её ступеньку.

Источник показывается **по параграфу, без номера страницы**: в казахском и русском изданиях номера параграфов совпадают, а страницы расходятся.

## Как запустить локально

Сборка не нужна — это статические файлы.

```bash
python -m http.server 5500 --directory frontend
```

Открыть `http://localhost:5500`.

Две оговорки:

- Открывать через локальный сервер, а не двойным щелчком по файлу. Регистрация использует `crypto.subtle` для хеширования пароля, а он работает только по `https` или с `localhost`.
- Запросы к `/api/ask` локально не работают: это serverless-функция Vercel. Чат и диагностика с ИИ проверяются на задеплоенном сайте.

## Как пересобрать поиск по учебнику

Нужен Python 3 и `requests`:

```bash
pip install requests
```

Ключ читается из переменной окружения — в коде его нет и быть не должно:

```powershell
$env:GEMINI_API_KEY = "ваш-ключ"     # Windows PowerShell
```

```bash
export GEMINI_API_KEY="ваш-ключ"     # Linux и macOS
```

Запуск:

```bash
python tools/build_chunks.py
```

Результат — `frontend/api/chunks.json`, он коммитится в репозиторий: serverless-функции он нужен во время деплоя.

### Формат исходного текста

Каждый фрагмент — строка с пятью полями через `|`, следом абзац текста:

```
### Математика | 5 класс | часть 1 | §23 | стр. 110
Текст абзаца одной строкой, без переносов внутри.
```

Скрипт останавливается с понятным сообщением, если полей не пять или если в поле класса или страницы нет числа. Формулы записываются обычным текстом (`a/c + b/c`, `a²`, `√16`) — без этого модель возвращает LaTeX, который в браузере выглядит мусором.

## Как пересобрать заготовленные ответы

```bash
python tools/build_answers.py
```

Скрипт берёт вопросы из `tools/demo_questions.txt` и по очереди обращается к **задеплоенному** `/api/ask`, складывая ответы в `frontend/api/answers.json`. Ключ ему не нужен. Смысл в том, что заготовки проходят через тот же порог, те же инструкции и ту же обработку, что и живые ответы — второй реализации, которая со временем разойдётся с основной, не появляется.

## Что в прототипе работает не полностью

Честный список — чтобы не пришлось догадываться по коду:

- **Прогресс сохраняется только в браузере.** Результат диагностики, закрытые темы и очки за задания пишутся в `localStorage` (`sabaqtas-diagnostic`, `sabaqtas-progress`) — они переживают перезагрузку страницы, но не переезд на другое устройство. Сами темы, вопросы и задания по-прежнему берутся из подготовленного `js/mock.js`, а данные в панели учителя — из `js/teacher-mock.js`.
- **Цепочка диагностики одна** — математическая, 8 → 7 → 6 → 5. Межпредметная линия (физика ломается о деление за 5 класс) спроектирована, но не реализована.
- **Экран темы показывает одну тему** — корневой пробел. Параметра в ссылке пока нет.
- **Физика и химия не загружены.** Архитектура от предмета не зависит: добавление нового предмета — это загрузка учебника, а не переписывание кода.
- **Неразглашение ответа наставником обеспечивается инструкцией в промпте**, а не проверкой в коде. Ограничение темы — наоборот, гарантия в коде (порог выше).
- **Авторизация упрощённая:** имя и пароль хешем SHA-256 в `localStorage`, без подтверждения почты.
