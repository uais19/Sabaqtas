# Sabaqtas

ИИ-платформа для обучения казахстанских школьников 7–12 классов.

Три ключевые особенности:

1. **Адаптивная диагностика.** Система идёт вниз по цепочке тем-пререквизитов и
   находит корневой пробел в знаниях — часто он на несколько классов ниже текущего.
2. **Режим наставника.** ИИ ведёт ученика к ответу наводящими вопросами и
   никогда не называет ответ сам.
3. **Ответы только по учебникам.** Все ответы ИИ строго основаны на загруженных
   школьных учебниках (RAG) и всегда содержат ссылку на параграф и страницу.

Язык интерфейса — русский. ИИ отвечает на русском или казахском.

## Стек

- **Frontend:** чистый HTML / CSS / JavaScript. Без фреймворков, без сборки.
- **Backend:** Python + FastAPI (пишет отдельный разработчик).
- **База данных:** Supabase Postgres.
- **ИИ:** Google Gemini API.

## Как запустить frontend

Отдельная сборка не нужна — это обычные статические файлы.

Самый простой способ: открыть `frontend/index.html` в браузере.

Либо поднять локальный сервер (ближе к реальным условиям, корректно работают
относительные пути и запросы к бэкенду):

```bash
python -m http.server 5500 --directory frontend
```

После этого открыть в браузере `http://localhost:5500`.
