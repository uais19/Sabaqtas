# CLAUDE.md — правила работы над проектом Sabaqtas

## О проекте

Sabaqtas — ИИ-платформа для обучения казахстанских школьников 7–12 классов.

Три ключевые особенности:

1. **Адаптивная диагностика.** Система идёт вниз по цепочке тем-пререквизитов и
   находит корневой пробел в знаниях ученика — часто он на несколько классов
   ниже текущего.
2. **Режим наставника (mentor mode).** ИИ ведёт ученика к ответу наводящими
   вопросами и НИКОГДА не называет ответ сам.
3. **Ответы только по учебникам.** Все ответы ИИ строго основаны на загруженных
   школьных учебниках (RAG) и всегда содержат ссылку на исходный параграф и
   страницу.

Язык интерфейса — русский. ИИ может отвечать на русском или казахском.

## Стек

- **Frontend:** чистый HTML / CSS / JavaScript. НЕТ фреймворков, НЕТ сборки
  (никаких npm-скриптов, бандлеров, транспиляции).
- **Backend:** Python + FastAPI. Его пишет другой разработчик.
- **База данных:** Supabase Postgres.
- **ИИ:** Google Gemini API.

## Зона ответственности

Редактировать можно только файлы внутри `frontend/`.
Папку `backend/` не трогать никогда — ни создавать в ней файлы, ни изменять,
ни удалять.

## ГЛАВНОЕ ПРАВИЛО: код должен быть объясним

Это хакатон. Автор обязан суметь объяснить судьям любую строчку кода.

- Пиши простой, читаемый, явный код.
- Никаких хитрых приёмов и «умных» однострочников.
- Никаких лишних абстракций: не создавай слой, пока он реально не нужен.
- Никаких библиотек, если об этом не попросили явно.
- Неочевидные места комментируй на русском языке.

## Секреты

Никогда не хардкодить API-ключи. Ключ Gemini живёт только на бэкенде, в
переменной окружения. Во фронтенде ключей нет вообще.

## Как вносить изменения

- Делай маленькие сфокусированные изменения — по одному экрану за раз.
- Не рефакторить и не перестраивать существующие файлы, если об этом не
  попросили явно.

## Git

После завершения каждого законченного изменения выполняй:
  git add .
  git commit -m "<короткое описание по-русски того, что изменилось>"
  git push
Не коммить файлы с ключами. Сообщение коммита пиши по существу:
"экран чата", "фикс порога отсечения" — не "update" и не "fixes".

## Порядок сборки экранов

1. Лендинг
2. Диагностика
3. Результат диагностики (корневой пробел)
4. Чат с ИИ с переключателем режима
5. Дашборд ученика
6. Тема и задания
7. Панель учителя
8. Вход (логин)
